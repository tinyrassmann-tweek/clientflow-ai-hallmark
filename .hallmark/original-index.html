A FEW THINGS TO KNOW.

Clarity from
the beginning.

Can I try the workspace first?

Yes. The interactive sample lets you create sample contacts, build an offer, and explore specialist drafts. Sample changes stay in your browser. Sign in to use persistent workspaces.

What works before I connect AI?

The CRM, offers, workflow checklists, staging, approvals, exports, and structured template drafts work without an AI key. Live AI generation requires a configured provider. Templates are labeled so you know how each draft was created.

Does ClientFlow send or publish automatically?

This release supports human-reviewed drafting and workflow tracking. Automated outreach, continuous CRM sync, booking agents, and direct publishing require additional connected services and setup. Recording a deployment URL does not publish a website.

How are client workspaces separated?

Workspace access is checked by the server for every request. Owners can share a time-limited invitation for an editor or viewer. Each workspace keeps its clients, drafts, workflows, and activity separate.

Can I use my own domain?

Yes. The deployment package supports Google Cloud Run with Firestore for persistent records and Firebase Authentication for sign-in. Your own domain can be connected after the service is deployed.
